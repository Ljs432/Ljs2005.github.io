今日学习总结

交叉编译工具链

今日学习内容

部署交叉编译工具链

sudo apt install gcc-arm-linux-gnueabihf

编写源码：创建基础测试程序

cat > test.cpp << EOF
#include
using namespace std;
int main() {
cout << “Hello Cross Compile C++!” << endl;
return 0;
}
EOF

交叉编译：翻译为 ARM 指令

arm-linux-gnueabihf-g++ test.cpp -o test_arm

验证结果：确认文件架构

file test_arm

其他知识

输出重定向符号
<< 告诉 Shell 接下来的输入会作为 cat 命令的输入
EOF 自定义的结束分隔符（End Of File）可以换成其他字符串（比如 END/FINISH），作用是标记输入内容的 “结束边界”

应用

ARM设备 嵌入式开发板、手机、物联网设备
