初识Modbus通信协议

今日学习内容

Modbus通信协议

Modbus协议使用的是主从通讯技术，即由主设备主动查询和操作从设备
主站发指令→从站响应，从站不会主动发数据；一次请求对应一次响应，超时未响应则重连
ModBus rtu采集基于数据链路层的应用层协议，用来串口设备和串口服务器进行通信
ModBus Tcp采集基于TCP/IP协议栈的应用层协议（TCP在传输层，IP在网络层） ，用来电脑和串口服务器通信
常见的主设备：上位机，PLC
常见的从设备：仪表类（最多）计量类 驱动与控制类 现场被读取、被控制、被动响应的设备
Modbus TCP 只是在 RTU 的基础上，加了 6 字节的 “快递面单”（MBAP 头），去掉了 CRC 校验，核心的 “地址 + 功能码 + 数据” 和 RTU 完全一样。

核心寄存器

离散输入（0xxxx） 读开关状态（比如按钮） 只读 00001 = 第一个输入点
线圈（1xxxx） 读写开关输出（比如继电器）读写 10001 = 第一个继电器
输入寄存器（3xxxx）读模拟量（比如温度） 只读 30001 = 第一个温度值
保持寄存器（4xxxx）读写模拟量 / 参数 读写 40001 = 设定的阈值

常用功能码

01 读线圈状态 读多个开关输出 请求：起始地址 + 数量； 响应：字节数 + 状态值

03 读保持寄存器 读多个模拟量 请求：起始地址 + 数量； 响应：字节数 + 寄存器值（每个 2 字节）

04 读输入寄存器 读传感器模拟量 和 03 格式完全一致

06 写单个保持寄存器 设单个参数 请求：地址 + 数值；响应：和请求一致（代表成功）

16 写多个保持寄存器 批量设参数 请求：地址 + 数量 + 字节数 + 数值；响应：地址 + 数量
