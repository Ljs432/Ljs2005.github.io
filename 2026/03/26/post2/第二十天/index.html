今日学习总结

交叉编译

今日学习内容

基本流程

写业务代码 → 写构建配置 → 生成 Makefile → 用 ARM 工具链编译 → 验证架构

创建 C++ 源文件

cat > hello_arm.cpp << ‘EOF’
#include
#include

int main() {
std::string msg = “Hello ARM (C++)!”;
std::cout << msg << std::endl;
return 0;
}
EOF

创建 premake4.lua 脚本

cat > premake4.lua << ‘EOF’
solution “ARM_CPP_Workspace”
configurations { “Release” }

project “hello_arm_cpp”
kind “ConsoleApp”
language “C++”
targetdir “.”
files { “hello_arm.cpp” }
EOF

生成 Makefile

生成 Linux 编译脚本
premake4 gmake

make 真正编译

验证结果

echo -e “\n编译完成，文件架构：”
file hello_arm_cpp

直接用命令行指定 ARM 编译器编译

rm -rf obj/ hello_arm_cpp
make -f hello_arm_cpp.make
CC=arm-linux-gnueabihf-gcc
CXX=arm-linux-gnueabihf-g++
LD=arm-linux-gnueabihf-g++

验证结果

echo -e “\n编译完成，文件架构：”
file hello_arm_cpp
