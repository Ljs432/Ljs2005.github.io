今日学习总结

Wireshark的使用

今日学习内容

界面三大核心区


数据包列表（上）：序号、时间、源 / 目的地址、协议、长度、摘要；点击列头可排序。
数据包详情（中）：协议树（Frame→Ethernet→IP→TCP/UDP→应用层），展开可看MAC/IP/ 端口 / 标志位 / 应用数据。
数据包字节（下）：十六进制 + ASCII 原始数据；点击详情字段，此处高亮对应字节。

抓包与过滤器（核心）

基本抓包操作

开始：鲨鱼鳍图标；停止：红色方块；保存：Ctrl+S（.pcapng）。

捕获过滤器（Capture Filter，抓包前设置）

作用：内核态预筛选，减少无效数据，节省内存。

仅抓指定IP

host 192.168.8.135

仅抓HTTP（80端口）

port 80

排除ARP广播

not arp

显示过滤器（Display Filter，抓包后设置）

作用：在已抓数据中精准筛选，不破坏原始文件。

源/目的IP匹配

ip.addr == 192.168.8.135

DNS（53端口）

udp.port == 53

tls

HTTPS 就是基于 TLS 的 HTTP

仅TCP SYN（连接请求）

tcp.flags.syn == 1
