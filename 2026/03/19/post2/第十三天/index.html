今日学习总结

认证的工业级 MQTT 通信步骤

今日学习内容

配置文件

用途： 设备能连上、按规矩通信

步骤：

配置文件:

修改 mosquitto.conf，末尾新增配置
listener 1883 0.0.0.0
allow_anonymous false
password_file D:\Company\Code\Mosquitto\pwfile.txt
log_dest file D:\Company\Code\Mosquitto\mosquitto.log

开通账号：管理员 CMD 执行 设置账号密码

mosquitto_passwd -c D:\Company\Code\Mosquitto\pwfile.txt admin

开服务器：继续在2的管理员 CMD 执行

cd /d D:\Company\Code\Mosquitto
mosquitto.exe -c mosquitto.conf -v 启动 Broker；

普通通信：开两个普通 CMD 分别执行发布 / 订阅命令（ -u admin -P 密码 -q 1 参数)
订阅消息 cd /d D:\Company\Code\Mosquitto

mosquitto_sub.exe -t title -v -u admin -P 123456 -q 1 title 可以变成想发的主题

发布者 cd /d D:\Company\Code\Mosquitto

mosquitto_pub.exe -t title -m message -u admin -P 123456 -q 1 message可以变成想发的信息

基础知识

-c 指定配置文件路径
-t 指定主题
-v 输出完整消息内容（主题+消息）
-u 指定用户名
-p 指定密码
-q 指定QoS
