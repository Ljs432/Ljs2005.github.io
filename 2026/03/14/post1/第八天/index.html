Sqlmap的基础使用

今日学习内容：

sqlmap基础

SQLMap 是一款开源的自动化 SQL 注入检测与利用工具，用 Python 编写，是安全测试人员和渗透测试者常用的工具之一。
主要功能
1. 自动检测 SQL 注入漏洞
支持 GET、POST、HTTP 头部注入、Cookie 注入等参数类型。
2. 数据库指纹识别
可识别数据库类型（如 MySQL、Oracle、PostgreSQL、MSSQL、SQLite 等）。
3. 数据提取
可获取数据库名、表名、列名，并导出数据，甚至读取服务器文件。
4. 执行系统命令（需有权限）
在特定数据库（如 MySQL、PostgreSQL）中可尝试执行操作系统命令。
5. 绕过防护
支持多种绕过技术（如混淆、编码、随机化参数）应对 WAF/IDS。

sqlmap的使用

查询当前⽤户下的所有数据库 –dbs

获取数据库表名 –tables


获取数据库字段名 –columns

列出数据库管理员的⻆⾊ –roles

查看当前账户是否为数据库管理员账户

遇到问题及解决方案

问题：

使用SQLMap对目标URL进行初步探测时，工具未能自动识别出注入点或检测过程被Web应用防火墙（WAF）拦截，导致扫描失败。

解决方案：

这是一个系统性的排查和绕过过程，需要结合多种参数和技术。
1.精确指定检测目标与方法
2 使用混淆脚本绕过WAF（核心步骤）
3调整请求特征以模拟正常流量
